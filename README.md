Однозвʼязний список в якому шукається елемент під номером (length*2/3)-1, 
де n загальна кількість елементів у списку.
При написанні використовувався java.
Для запуску:
1)відкрийте будь-який редактор з підтримкою джава(писалося і тестувалося в VS code) та запустіть в ньому файл
2)Введіть елементи списку(або приберіть їх із коментарів) в кінці коду, місце для цього підписане коментарем "//елементи для тесту"
3)прочитайте анекдот:
– Ось хочу пошту без спамy, що порадиш?
– Голубів.
